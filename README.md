
# Intercom Directory

A intercom directory for a Work Immersion project for a hospital, meant to simplify to find contacts, intercoms and emails for certain departments.



## Environment Variables and Requirements

To run this project, you will need to add the following environment variables to your .env file

### Variables

`vendor` for using PHP related environment variables

`phpdotenv` For compiling every variable the system Requirements

### Applications

`Cloudflare` to run a simple and free server to be accessible remotely

`Composer` to install dependencies for PHP



## Tech Stack

**Client:** HTML, CSS, Vanilla JavaScript

**Server:** PHP, Python
