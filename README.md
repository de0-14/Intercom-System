# DRMC Intercom Directory & Messaging System

A secure, hierarchical, and real-time Intercom Directory and internal messaging platform designed for hospital organizational communication (Divisions, Departments, Units, and Offices). The system features an automated, background conversation archiver to maintain database performance and clear active workspace interfaces.

## 🚀 Features

- **Hierarchical Directory Management:** Seamless management of institutional levels: Divisions ➔ Departments ➔ Units ➔ Offices.
- **Dynamic Structural Forms:** Real-time filtered administrative dropdown selection with automatic cascading field updates.
- **Two-Tier Messaging Subsystems:**
  - **Intercom Chat:** Frontline users can open messaging threads targeting specific departmental endpoints managed by designated "Head Users".
  - **Admin Panel Chat:** Direct internal support communication channel linking platform Administrators and standard staff members.
- **Smart Activity Tracking:** Active tracking and storage of individual runtime user sessions and message interactions.
- **Transactional Maintenance Controls:** Automated background workflows utilizing high-performance query boundaries to archive inactive sessions without disrupting operational availability.
- **Granular Role-Based Access Control (RBAC):** Explicit operational context constraints based on user hierarchy:
  - `1` - Admin
  - `2` - MCC
  - `3` - Division Head
  - `4` - Department Head
  - `5` - Unit Head
  - `6` - Office Head
  - `7` - Staff

---

## 🛠️ Technology Stack

- **Backend Language:** PHP (OOP & Structural Mix)
- **Database Engine:** Microsoft SQL Server (Transact-SQL)
- **Database Driver:** Microsoft Drivers for PHP for SQL Server (`sqlsrv`)
- **Frontend Layer:** HTML5, CSS3 Custom Properties, Vanilla JavaScript (Fetch API Engine)
- **Automation Framework:** Windows Batch Executable Engine + Task Scheduler
